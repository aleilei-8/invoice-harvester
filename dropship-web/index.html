怎么放到手机上随时打开？
本页是纯前端单文件，三种方式任选：
① 最省事：用任意静态托管（Vercel / Cloudflare Pages / GitHub Pages）拖这个 html 上去，得到 https 链接，手机浏览器收藏即可。
② 零托管：把 index.html 发到微信文件传输助手，手机用浏览器打开（部分复制功能在 http/file 下可能受限，建议托管）。
③ iOS：Safari 打开后「分享 → 添加到主屏幕」，就像 App 一样。
